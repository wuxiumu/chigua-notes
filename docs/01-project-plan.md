### 3.6 TopHub 采集器（已完成）

**数据源**: `https://api.meiyoufan.com/tophub/` — 25 个平台、275 条热榜

**缓存目录结构**:
```
backend/data/cache/tophub/
├── 知乎/2026-05-30/{md5}.json    (37 条)
├── 微博/2026-05-30/{md5}.json    (107 条)
├── 虎扑社区/2026-05-30/{md5}.json (50 条)
├── Zaker/2026-05-30/{md5}.json    (22 条)
└── ... 共 25 个站点 / 259 条
```

**黑名单**: 命中 `如何看待`、`为什么年轻人` 等关键词则跳过不缓存

**验证**: 二次运行显示全部 259 条已存在，去重正常

**用法**:
```bash
php backend/scrapers/tophub-scraper.php            # 正常采集
php backend/scrapers/tophub-scraper.php --dry-run   # 预览模式
php backend/scrapers/tophub-scraper.php --stats     # 缓存统计
```
