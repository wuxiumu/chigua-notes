> **最后更新**: 2026-05-30

## 2. 后端 API 设计

### 2.1 获取缓存热榜列表

```
GET /api/admin/cache?site=IT之家&date=2026-05-30&q=关键词&page=1
```

读取 `backend/data/cache/tophub/{site}/{date}/` 目录下所有 `.json` 文件

**响应：**
```json
{
  "items": [
    {
      "ID": "239633859",
      "md5": "17061a1a963d51b4",
      "title": "释永信一审被判有期徒刑 24 年...",
      "sitename": "知乎",
      "url": "https://www.zhihu.com/...",
      "views": "2632 万热度",
      "extra": "2632 万热度",
      "time": "1780061424",
      "fetched_at": "2026-05-30 14:30:13"
    }
  ],
  "total": 37,
  "site": "知乎",
  "date": "2026-05-30"
}
```

### 2.2 获取站点列表（有缓存的）

```
GET /api/admin/cache-sites
```

**响应：**
```json
[
  { "site": "知乎", "dates": ["2026-05-30", "2026-05-29"], "total": 37 },
  { "site": "微博", "dates": ["2026-05-30"], "total": 107 },
  ...
]
```

### 2.3 AI 生成文章（预览）

```
POST /api/admin/generate
{
  "items": [
    {"md5": "...", "title": "标题1", "sitename": "IT之家"},
    {"md5": "...", "title": "标题2", "sitename": "知乎"},
    {"md5": "...", "title": "标题3", "sitename": "微博"}
  ],
  "site_slug": "ai",
  "custom_prompt": "重点关注技术细节和代码方面"  // 可选
}
```

将勾选的条目标题拼接到 prompt 中，调用千问生成完整文章。

**响应（不写文件，仅预览）：**
```json
{
  "ok": true,
  "title": "文章标题",
  "summary": "一句话摘要",
  "body": "## Markdown 正文...",
  "timeline": [{"happened_at": "...", "title": "...", "detail": "..."}],
  "opinions": [{"side": "official", "source": "...", "content": "..."}],
  "persons": [{"name": "..."}],
  "latency_ms": 5000,
  "usage": {"total_tokens": 3200}
}
```

### 2.4 确认发布

```
POST /api/admin/publish
{
  "title": "...",
  "summary": "...",
  "body": "...",
  "timeline": [...],
  "opinions": [...],
  "persons": [...],
  "site_slug": "ai"
}
```

**响应：**
```json
{
  "ok": true,
  "file": "009-claude-opus-48-digested.md",
  "slug": "claude-opus-48-digested"
}
```

### 2.5 缓存统计

```
GET /api/admin/stats
```

**响应：**
```json
{
  "cache": {
    "sites": 25,
```

## 5. 核心流程

```
用户打开 /admin
     ↓
GET /api/admin/cache-sites → 渲染站点树
     ↓
用户点击「知乎」→ GET /api/admin/cache?site=知乎&date=2026-05-30
     ↓
渲染热榜列表（搜索/过滤/排序）
     ↓
用户勾选 3 条热榜 → 点击「AI 生成文章」
     ↓
POST /api/admin/generate { items: [...], site_slug: "ai" }
     ↓
千问 API 调用 → 返回文章（预览模式，不写文件）
     ↓
弹窗展示 AI 生成结果（可编辑）
     ↓
用户确认 → POST /api/admin/publish
     ↓
写入 backend/data/events/009-xxx.md → 前端自动刷新显示
```

## 6. AI Prompt 设计

```
你是一个专业的科技新闻编辑。请根据以下热榜标题，撰写一篇完整的新闻事件文章。

## 目标子站: AI呀呀 (ai)

## 热榜来源（用户勾选的条目）:
1. [IT之家] 美国最强大模型 Claude Opus 4.8 刚上线就被曝"蒸馏"中国模型...
2. [知乎] 如何看待 5 月 29 日发布的 Claude4.8Opus 疑似大量蒸馏国内开源模型？
3. [36氪] Claude Opus 4.8 发布，多项基准测试超越 GPT-4o...

## 要求
1. 标题简洁有力，适合搜索引擎，不超过 50 字
2. 摘要 100 字以内，概括事件核心
3. 正文按「事件背景 → 详细经过 → 争议焦点 → 各方回应 → 后续影响」结构
4. 时间线按时间顺序排列，每条包含 happened_at、title、detail
5. 观点至少 3 条，覆盖官方(official)、媒体(media)、网友(player)
6. 保持中立客观，不加入个人判断
7. 中文输出

## 输出格式（必须输出纯 JSON）
{
  "title": "文章标题",
  "summary": "摘要",
  "body": "Markdown 正文",
  "timeline": [
    {"happened_at": "YYYY-MM-DD HH:mm", "title": "节点标题", "detail": "详情"}
  ],
  "opinions": [
    {"side": "official|media|player", "source": "来源", "content": "内容"}
  ],
  "persons": [
    {"name": "相关人物"}
  ]
}
```
